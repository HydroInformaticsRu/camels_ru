## Notes for CAMELS-RU manuscript workflow

- Core paper-structure exemplars: Addor et al. 2017 (CAMELS-US), Alvarez-Garreton et al. 2018 (CAMELS-CL), and CAMELS-SPAT 2025.
- Recent HESS framing exemplars: CAMELS-Chem 2024 and CAMELS/Caravan 2024 for dataset augmentation/intercomparison language.
- Adjacent but useful for Russian Federation framing: E-OBS/EStreams 2026 for forcing-product comparison and European large-sample hydrology context.
- Next workflow step should be a structured comparison matrix: title/abstract pattern, dataset components, quality-control claims, attribute groups, validation figures, data availability wording, limitations, and HESS-style review risks.
