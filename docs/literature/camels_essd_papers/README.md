## CAMELS-RU workflow notes

- These papers remain useful CAMELS data-descriptor exemplars, but CAMELS-RU has pivoted to HESS; use them as structure/QC/data-availability references rather than as target-journal models.
- France and Denmark are accepted ESSD dataset descriptor exemplars; GB v2 and Colombia are ESSD Discussions preprints and should be treated as current but not final.
- Use these together with HESS CAMELS-CL 2018 for a comparison matrix across national CAMELS descriptor structure, QC language, forcing choices, gauge/catchment inclusion rules, and data availability statements.
